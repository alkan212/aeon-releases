# ÆON

Build 3D worlds, publish them, and visit other people's.

## Install (Windows 10/11, 64-bit)

1. Download **[AEON-Setup.exe](https://github.com/alkan212/aeon-releases/releases/latest/download/AEON-Setup.exe)** — always the newest version.
2. Run it. Windows may say *"Windows protected your PC"* (the installer isn't signed yet): click **More info → Run anyway**.
3. ÆON installs for your Windows user only (no admin needed) and appears in the Start menu.

Links like `aeon://world/CZF-Z9K` open a world in ÆON. To uninstall: Windows Settings → Apps → ÆON (your projects stay).

Every version: [Releases](https://github.com/alkan212/aeon-releases/releases).
